# Ya Music Downloader

Десктопное приложение для загрузки треков, альбомов, плейлистов и дискографий
исполнителей с Яндекс.Музыки. Объединяет Electron-интерфейс и Python-ядро
(`ymd.ipc`), которое выполняет реальную загрузку и проставление метаданных.

## Возможности

- Загрузка треков, альбомов, плейлистов и дискографий по ссылке Яндекс.Музыки.
- Качество: низкое / обычное / Lossless (FLAC).
- Встраивание обложек альбомов в теги (Mutagen).
- Синхронная лирика в формате LRC и/или текст.
- Однократная OAuth-авторизация через Яндекс ID с сохранением токена.
- Пропуск уже скачанных файлов, настраиваемый шаблон пути (`{artist}/{album}/{title}`).
- Прогресс и лог в реальном времени, отмена загрузки.
- Кроссплатформенная сборка: портативный `.exe` (Windows) и `.rpm` (Linux).

## Требования

- Node.js 20+ и npm.
- Python 3.10+ (рекомендуется 3.14) с виртуальным окружением, в котором
  установлены зависимости проекта (`yandex-music`, `mutagen`, `pycryptodome` и др.).
- По умолчанию Python-интерпретатор ищется по пути
  `/opt/yandex-music-downloader/venv/bin/python` (переопределяется через
  переменную окружения `PYTHON_BIN`).

## Быстрый старт

```bash
npm --prefix electron-app install
./run-mvp.sh
```

При первом запуске нажмите «Войти через Яндекс ID» — откроется окно OAuth,
после успешного входа токен сохранится в
`~/.config/yandex-music-downloader/auth.json`. Повторный запуск покажет бейдж
«Авторизован».

## Сборка пакетов

```bash
./build-all.sh
```

Скрипт соберёт портативный `.exe` (Windows) и `.rpm` (Linux). Готовые
артефакты помещаются в каталог `artifacts/`. Для сборки RPM используется
`nfpm` (скачивается автоматически, если не установлен).

## Безопасность

- Токен доступа никогда не передаётся через аргументы командной строки — он
  доставляется в Python-sidecar через переменную окружения `YMD_TOKEN` в
  очищенном окружении дочернего процесса.
- Токен хранится в `~/.config/yandex-music-downloader/auth.json` с правами
  `0600`; каталог создаётся с `0700`.
- В `stderr`, трейсбеках и отладочных логах значения токена маскируются.
- `--path-pattern` валидируется в обоих слоях (Electron и Python) на
  отсутствие `..`, абсолютных путей и сегментов `.`; итоговые пути проверяются
  на попадание в выбранную папку загрузки.

Подробнее — в `SECURITY.md`. Перед публикацией запустите
`bash scripts/pre-publish-audit.sh`.
